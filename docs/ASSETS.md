# Assets

Every non-code file that is not obviously ours, with where it comes from. **Please do not add a file without adding a line here.**

| File | What | Origin / license |
|---|---|---|
| `IntroMusic.mp3` | the start-up chime/music | **origin and license not recorded: confirm you may redistribute it before a public release, or replace it with something you made or that is freely licensed** |
| `pwa/icon-*.png`, `pwa/manifest.webmanifest` | the phone app's icons | generated for this project |
| `posters-curated.json` | a hand-picked list of films and shows (titles, years, one-line blurbs) | facts and our own short text; images are fetched from TMDB at run time |
| `tools/arcade_gamelist.xml` | a list of arcade game names | names only; no ROMs or artwork |
| `qrcode.js` | QR code library (official qrcode-generator 1.4.4, MIT) | see [THIRD_PARTY.md](../THIRD_PARTY.md) |
| `themes/*` | CSS, scripts, emoji | written for this project; emoji are rendered by the viewer's system font |

Screenshots and the promo film are not part of the public repository: they show other people's album art and real names.
